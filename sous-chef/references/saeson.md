# Dansk sæson - hvad der er bedst og billigst lige nu

Læs denne fil i trin 3, FØR du søger. Så bruges søgningen på inspiration og konkrete opskrifter,
ikke på at slå op om der er asparges i august. Foreslå med sæsonen, ikke imod den: det smager
bedre, koster mindre, og "de første nye kartofler" eller "grønkål efter første frost" er i sig
selv et argument, brugeren kan mærke.

Tabellen er højsæson i Danmark (friland medmindre andet står). Væksthus-tomat og -agurk findes
hele året, men smager af noget fra maj til oktober.

| Måned | Højsæson |
|---|---|
| **Januar** | Grønkål, rosenkål, rødkål, hvidkål, spidskål (lager), porre, jordskokker, gulerod, pastinak, persillerod, knoldselleri, rødbede, æbler (lager) |
| **Februar** | Som januar. Stenbiderrogn begynder. Sidste chance for ordentlige jordskokker |
| **Marts** | Rodfrugter og kål på lager, porre, stenbiderrogn, skovsyre. Tyndt - planlæg efter lagervarerne, ikke efter foråret |
| **April** | Ramsløg, rabarber, spinat, radiser, hvidløgskarse, de sidste rodfrugter, stenbiderrogn slutter |
| **Maj** | Asparges (hvide og grønne), rabarber, spinat, radiser, salat, purløg, de allerførste nye kartofler sidst på måneden |
| **Juni** | Jordbær, nye kartofler, asparges (først på måneden), ærter, hyldeblomst, salat, dild, sommerkål (spidskål) |
| **Juli** | Jordbær, hindbær, solbær, stikkelsbær, kirsebær, nye kartofler, ærter, bønner, squash, blomkål, agurk, fennikel |
| **August** | Tomater, majs, bønner, squash, blommer, brombær begynder, blomkål, broccoli, fennikel, løg, de første æbler, hyldebær sidst på måneden |
| **September** | Æbler, pærer, blommer, brombær, svampe (kantareller, Karl Johan), majs, græskar begynder, kål vender tilbage, porre |
| **Oktober** | Græskar, æbler, pærer, kvæder, svampe, jordskokker, rosenkål begynder, alle kål, rodfrugter, muslinger er gode igen |
| **November** | Grønkål (bedst efter frost), rosenkål, alle kål, rodfrugter, porre, jordskokker, æbler og pærer på lager, muslinger |
| **December** | Som november. Grønkål, rødkål og and(-etid) - klassikerne ER sæsonen |

Kort om det fra vandet: **muslinger og østers** er bedst i de kolde måneder (september-april),
**stenbiderrogn** februar-april, **sild** er stabil året rundt, **makrel** er sommer (juni-august),
**torsk** er bedst om vinteren.

Brug tabellen som rygrad, ikke som facit - en tidlig sommer flytter jordbærrene, og importvarer
findes altid. Men står valget frit, så vælg det der har højsæson: det er dér, retten bliver bedre
end brugerens forventning.
